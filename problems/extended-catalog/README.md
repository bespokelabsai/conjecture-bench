# Extended catalog

5,221 problems from published collections, one JSON file per problem, grouped
by source. Each record holds the problem statement or a pointer to it, where it
came from, and its recorded status.

Kourovka entries carrying an answer annotation remain with status
`reported-answered-by-source`; this is attribution, not independent verification.
Unclear or conflicting source status also remains explicit.

All 652 Erdős records carry a pointer rather than statement text.

| Source | Records |
| --- | ---: |
| unsolvedmath.com | 2,075 |
| Kourovka Notebook | 1,307 |
| Formal Conjectures (Lean) | 1,031 |
| Erdős Problems | 652 |
| EGRES Open | 95 |
| Open Problems Project | 61 |

Every record names its source and includes a stable locator. `review_flags`
make unresolved statement, provenance, or status concerns explicit.
`related_conjecture_ids` links catalog entries to the curated set.
